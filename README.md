# StreamPing 배포판

StreamPing은 OBS Studio에서 방송을 시작하면 치지직 채널의 LIVE 상태를 확인한 뒤
Discord에 알림을 보내고, 방송 정보가 입력된 X 작성 화면을 여는 Windows용 플러그인입니다.

## 베타 안내

**StreamPing은 현재 베타 버전입니다.**

치지직 LIVE 상태와 방송 정보는 치지직 공식 Open API가 아니라 치지직 웹 서비스에서
사용하는 공개 `live-detail` 엔드포인트를 통해 확인합니다. 별도의 API 키는 필요하지 않지만,
치지직이 이 방식의 호환성을 보장하지는 않습니다.

치지직의 엔드포인트나 응답 형식이 변경되면 LIVE 확인, 방송 제목, 카테고리 또는 썸네일
표시가 일시적으로 작동하지 않을 수 있습니다. 문제가 발생하면 [문제 해결](#문제-해결)을
확인하고 최신 버전으로 업데이트해 주세요.

## 주요 기능

- OBS 방송 시작 시 치지직 LIVE 상태 자동 확인
- Discord 채널 선택 방식의 간편 연결 및 자동 알림
- 현재 방송 정보를 반영한 Discord 알림과 메시지 테스트
- 방송 정보가 입력된 X 작성 화면 열기
- Discord와 X 메시지 템플릿 편집
- OBS 설치 위치 자동 탐색 및 기존 버전 업데이트
- 새 버전 자동 확인 및 중요도별 업데이트 알림

## 요구 사항

- Windows 10 이상
- OBS Studio 64비트
- 인터넷 연결

## 다운로드

- [최신 Windows 버전 바로 다운로드](https://github.com/TereBin/StreamPing-Release/releases/latest/download/StreamPing-windows-x64.zip)
- [최신 릴리스 페이지와 변경 사항 보기](https://github.com/TereBin/StreamPing-Release/releases/latest)

다운로드한 ZIP은 릴리스에 첨부된 `SHA256SUMS.txt`로 무결성을 확인할 수 있습니다.

## 설치 및 업데이트

1. OBS Studio를 완전히 종료합니다.
2. 다운로드한 ZIP 파일의 압축을 풉니다.
3. 압축을 푼 폴더에서 `install.cmd`를 실행합니다.
4. 관리자 권한 요청이 나타나면 승인합니다.
5. `StreamPing 업데이트가 완료되었습니다.`라는 메시지를 확인합니다.
6. OBS를 실행하고 **도구 > StreamPing 설정**을 엽니다.

설치 프로그램은 OBS 설치 위치를 자동으로 찾습니다. 기존 StreamPing이 있으면 DLL을
`streamping.dll.bak`으로 백업한 뒤 새 버전으로 교체합니다. 이후 업데이트도 같은 순서로
진행하면 됩니다.

StreamPing은 기본적으로 OBS 실행 후 하루에 한 번 새 버전을 확인합니다. 업데이트 중요도에
따라 선택, 권장 또는 필수 알림을 표시하며, 필수가 아닌 버전은 건너뛸 수 있습니다. 자동으로
설치하지는 않으며, 설정 화면의 **업데이트 > 지금 확인**에서 직접 확인하거나 자동 확인을
끌 수 있습니다.

### 포터블 OBS 또는 자동 탐색 실패 시

명령 프롬프트에서 `bin\64bit\obs64.exe`가 들어 있는 OBS 최상위 폴더를 지정합니다.

```bat
install.cmd -ObsPath "D:\Apps\obs-studio"
```

## 설정 방법

### 1. 치지직 채널 설정

1. **치지직 > 채널**에 알림을 보낼 치지직 채널 URL 또는 32자리 채널 ID를 입력합니다.
2. **치지직 확인**을 눌러 채널 이름과 현재 LIVE 상태를 확인합니다.
3. 설정 창 아래의 **저장**을 누릅니다.

채널 URL을 입력하면 StreamPing이 채널 ID를 자동으로 추출합니다. 한 번 저장한 채널은 OBS를
종료하거나 다시 실행해도 유지되므로, 채널이 바뀌지 않는 한 다시 입력할 필요가 없습니다.

### 2. Discord 알림 설정

#### 기본 연결

1. **방송 시작 시 Discord 자동 알림**을 체크합니다.
2. **Discord 연결**을 누릅니다.
3. 브라우저에서 Discord에 로그인합니다.
4. 알림을 받을 서버와 채널을 선택하고 권한을 승인합니다.
5. StreamPing의 Discord 상태에 연결한 채널이 표시되는지 확인합니다.
6. 메시지를 편집하고 **알림 메시지 테스트**를 눌러 실제 알림을 확인합니다.
7. 설정 창 아래의 **저장**을 누릅니다.

선택한 Discord 채널에서 Webhook을 만들 수 있는 권한이 필요합니다. 알림에는 전송 직전에
확인한 방송 제목, 채널, 카테고리와 가능한 경우 LIVE 썸네일이 표시됩니다.

#### 역할 멘션 설정

역할 멘션은 선택 기능입니다. 역할이 필요하지 않으면 이 절차를 건너뛰어도 됩니다.

1. StreamPing 설정의 Discord 섹션에서 **역할 선택**을 누릅니다.
2. 설정 창 아래에 **연결된 Discord 채널에서 /streamping-role 명령으로 역할을 선택해
   주세요.**라는 문구가 표시되는지 확인합니다.
3. 앞에서 알림을 받도록 연결한 Discord 채널로 이동합니다.
4. 해당 채널의 메시지 입력란에서 `/streamping-role` 명령을 선택해 실행합니다.
5. Discord에 표시되는 선택 항목에서 멘션할 역할을 고릅니다.
6. StreamPing의 Discord 상태에 선택한 역할 이름이 표시되는지 확인합니다.
7. 메시지에서 멘션할 위치에 `{role}`을 넣고 **알림 메시지 테스트**를 실행합니다.

`/streamping-role`은 다른 채널이 아니라 실제 알림을 받도록 연결한 채널에서 실행해야 합니다.
역할을 바꾸려면 **역할 선택**을 다시 누르고 같은 절차를 진행합니다. 역할 멘션을 없애려면
**역할 해제**를 누릅니다.

#### 메시지 작성

Discord와 X 메시지에는 다음 변수를 사용할 수 있습니다.

| 변수 | 내용 | 사용 위치 |
| --- | --- | --- |
| `{role}` | 선택한 Discord 역할 멘션 | Discord만 |
| `{title}` | 방송 제목 | Discord, X |
| `{category}` | 방송 카테고리 | Discord, X |
| `{channel}` | 치지직 채널 이름 | Discord, X |
| `{url}` | 치지직 방송 주소 | Discord, X |

각 변수는 알림을 만들 때 실제 방송 정보로 바뀝니다. 역할을 선택하지 않은 상태의 `{role}`은
빈 문자열이 되며, 역할을 선택했더라도 메시지에 `{role}`이 없으면 멘션하지 않습니다.

멘션 없이 보내는 예시:

```text
🔴 {channel} 방송 시작!

{title}
카테고리: {category}
{url}
```

선택한 역할을 멘션하는 예시:

```text
{role} 방송이 시작됐어요!

{title}
{url}
```

서버 전체 또는 현재 온라인 구성원을 멘션하려면 메시지에 `@everyone`이나 `@here`를 직접
입력합니다. Discord 서버와 채널에서 해당 멘션 권한이 허용되어 있어야 실제 알림이 전달됩니다.

```text
@everyone {channel} 방송 시작!
{title}
{url}
```

```text
@here 지금 방송을 시작합니다!
{title}
{url}
```

#### 연결 해제와 수동 Webhook

**Discord 연결**로 생성한 연결은 **연결 해제**를 누르면 Webhook도 함께 삭제됩니다.

간편 연결을 사용할 수 없는 경우 **수동 Webhook (고급)**에 Discord Webhook URL을 직접
입력할 수 있습니다. 수동 Webhook은 **연결 해제**를 눌러도 Discord 서버에서 자동으로
삭제되지 않으므로 Discord 채널 설정에서 직접 관리해야 합니다.

### 3. X 작성 화면 설정

1. **방송 시작 시 X 작성 화면 열기**를 체크합니다.
2. 메시지를 편집하고 **X 작성 화면 테스트**를 누릅니다.
3. 브라우저에 방송 정보가 입력된 X 작성 화면이 열리는지 확인합니다.
4. 설정 창 아래의 **저장**을 누릅니다.

X에는 자동으로 게시하지 않습니다. 방송 시작 시 작성 화면만 열리며, 문구와 계정을 확인한
뒤 사용자가 직접 게시해야 합니다. 사용 가능한 메시지 변수는 [메시지 작성](#메시지-작성)을
참고하세요.

### 4. LIVE 확인 설정

대부분의 경우 기본값을 그대로 사용하면 됩니다. 조정이 필요할 때만 접혀 있는 **LIVE 확인**을
눌러 다음 항목을 변경합니다.

| 항목 | 기본값 | 설명 |
| --- | ---: | --- |
| 첫 확인 지연 | 5초 | OBS 방송 시작 후 첫 치지직 확인까지 기다리는 시간 |
| 확인 간격 | 5초 | 아직 LIVE가 아닐 때 다시 확인하는 간격 |
| 최대 대기 | 120초 | LIVE 확인을 계속 시도하는 최대 시간 |

치지직의 LIVE 반영이 OBS보다 늦을 수 있으므로 StreamPing은 최대 대기 시간 동안 반복해서
확인합니다. 같은 방송에는 Discord 알림과 X 작성 화면을 각각 한 번만 실행합니다.

## 제거

1. OBS Studio를 완전히 종료합니다.
2. 가능하면 먼저 StreamPing 설정에서 Discord **연결 해제**를 눌러 생성된 Webhook을 삭제합니다.
3. OBS 설치 폴더에서 다음 항목을 삭제합니다.

```text
obs-plugins\64bit\streamping.dll
data\obs-plugins\streamping\
```

## 문제 해결

### `도구` 메뉴에 `StreamPing 설정`이 없음

- **확인:** OBS에서 **도움말 > 로그 파일 > 현재 로그 보기**를 열고 `[StreamPing] Plugin
  loaded`를 검색합니다.
- **해결:** 해당 문구가 없다면 OBS를 완전히 종료하고 최신 ZIP의 `install.cmd`를 다시
  실행합니다. 기본 설치에서는 다음 파일이 있어야 합니다.

  ```text
  C:\Program Files\obs-studio\obs-plugins\64bit\streamping.dll
  C:\Program Files\obs-studio\data\obs-plugins\streamping\locale\ko-KR.ini
  ```

### 로그에 이전 플러그인 버전이 표시됨

- **확인:** 로그의 `[StreamPing] Plugin loaded (version ...)`을 [최신 릴리스
  페이지](https://github.com/TereBin/StreamPing-Release/releases/latest)의 버전과 비교합니다.
- **해결:** OBS를 완전히 종료하고 [최신 ZIP](https://github.com/TereBin/StreamPing-Release/releases/latest/download/StreamPing-windows-x64.zip)을
  다시 내려받아 설치합니다. OBS가 실행 중이면 기존 DLL이 교체되지 않습니다.

### 설치 프로그램이 OBS를 찾지 못함

- **확인:** OBS 최상위 폴더 안에 `bin\64bit\obs64.exe`가 있는지 확인합니다.
- **해결:** [포터블 OBS 또는 자동 탐색 실패 시](#포터블-obs-또는-자동-탐색-실패-시)의
  `-ObsPath` 옵션으로 해당 폴더를 직접 지정합니다.

### OBS가 실행 중이라는 오류가 표시됨

- **확인:** 작업 표시줄과 시스템 트레이에 OBS가 남아 있는지 확인합니다.
- **해결:** OBS를 완전히 종료한 뒤 `install.cmd`를 다시 실행합니다. 계속 표시되면 작업
  관리자에서 `obs64.exe`가 종료됐는지 확인합니다.

### `치지직 응답 오류 (0): TLS initialization failed`가 표시됨

- **확인:** OBS 로그에서 StreamPing 버전을 확인합니다. 이 오류는 Qt TLS 구성 요소를 사용하던
  이전 빌드에서 발생할 수 있습니다.
- **해결:** OBS를 완전히 종료하고 최신 ZIP을 다시 설치합니다. 현재 버전은 Windows의
  WinHTTP를 사용하므로 별도의 Qt TLS DLL을 복사할 필요가 없습니다.

### 치지직 채널을 확인할 수 없음

- **확인:** [치지직 채널 설정](#1-치지직-채널-설정)에 입력한 URL 또는 32자리 채널 ID와
  인터넷 연결을 확인합니다. 설정 창 아래의 오류 문구도 함께 확인합니다.
- **해결:** 전체 치지직 채널 URL을 다시 붙여 넣고 **치지직 확인**을 누릅니다. 계속 실패하면
  치지직 웹사이트에서 해당 채널을 열 수 있는지 확인한 뒤 최신 버전으로 업데이트합니다.

### Discord 연결 버튼을 눌러도 브라우저가 열리지 않음

- **확인:** Windows 기본 브라우저 설정, 인터넷 연결, 설정 창 아래의 오류 문구를 확인합니다.
- **해결:** 기본 브라우저를 지정하고 OBS를 다시 실행합니다. VPN, 프록시 또는 보안 프로그램이
  연결을 차단한다면 다른 네트워크에서 다시 시도하되 Windows 보안 기능을 끄지는 마세요.

### Discord 승인 후에도 연결이 완료되지 않음

- **확인:** 브라우저에 완료 화면이 표시됐는지, 선택한 Discord 채널에서 Webhook을 만들 수
  있는 권한이 있는지 확인합니다.
- **해결:** OBS로 돌아와 잠시 기다립니다. 계속 실패하면 **Discord 연결**을 다시 누르고 서버와
  채널을 선택합니다. 승인 과정 중에는 OBS나 설정 창을 닫지 마세요.

### Discord 역할을 선택할 수 없음

- **확인:** StreamPing에서 **역할 선택**을 먼저 눌렀는지, `/streamping-role` 명령을 실제
  알림을 받도록 연결한 채널에서 실행했는지 확인합니다.
- **해결:** [역할 멘션 설정](#역할-멘션-설정)의 순서대로 다시 진행합니다. 명령을 실행하는
  사용자는 해당 채널의 Webhook을 관리할 권한이 있어야 합니다.

### Discord 알림이 오지 않음

- **확인:** Discord 자동 알림이 체크돼 있는지 확인하고 **치지직 확인**과 **알림 메시지
  테스트**를 차례로 실행합니다.
- **해결:** 테스트 결과에 따라 치지직 채널이나 Discord 연결을 다시 설정하고 **저장**을
  누릅니다. 실제 자동 알림은 OBS 방송 시작 후 치지직에서 LIVE가 확인될 때 한 번 전송됩니다.

### Discord 메시지는 오지만 멘션 알림이 오지 않음

- **확인:** 메시지에 `{role}`, `@everyone` 또는 `@here`가 들어 있는지 확인합니다. 역할 이름을
  일반 텍스트로 입력한 것만으로는 멘션되지 않습니다.
- **해결:** 역할 멘션은 [역할 멘션 설정](#역할-멘션-설정)을 완료한 뒤 `{role}`을 사용합니다.
  `@everyone`과 `@here`는 Discord 서버와 채널에서 해당 멘션 권한을 허용해야 합니다.

### X 작성 화면이 열리지 않음

- **확인:** Windows 기본 브라우저 설정과 팝업 차단 여부를 확인한 뒤 **X 작성 화면 테스트**를
  실행합니다.
- **해결:** 기본 브라우저를 지정하고 OBS를 다시 실행합니다. X에는 자동 게시되지 않으므로
  열린 작성 화면에서 사용자가 직접 내용을 확인하고 게시해야 합니다.

### 새 버전 알림이 표시되지 않음

- **확인:** StreamPing은 자동 확인을 켠 상태에서 마지막 확인 후 24시간이 지나야 OBS 시작 후
  다시 확인합니다.
- **해결:** 인터넷 연결을 확인하고 설정의 **업데이트 > 지금 확인**을 누릅니다. 알림이 없어도
  [최신 릴리스 페이지](https://github.com/TereBin/StreamPing-Release/releases/latest)에서 직접
  버전을 확인할 수 있습니다.

### 다운로드 또는 검사 중 Defender가 파일을 차단함

- **확인:** Windows 보안의 **바이러스 및 위협 방지 > 보호 기록**에서 탐지 이름과 영향을 받은
  파일을 확인합니다. 릴리스의 `SHA256SUMS.txt`와 ZIP 파일의 체크섬도 비교합니다.
- **해결:** Windows 보안 기능을 끄거나 예외를 추가하지 마세요. 설치를 중단하고 탐지 이름과
  파일명을 포함해 아래 [문제 보고](#문제-보고)에 따라 알려 주세요. Webhook이나 설정 파일은
  첨부하지 마세요.

문제가 계속되면 아래 [문제 보고](#문제-보고)를 참고해 이슈를 등록해 주세요.

## 보안과 소스 코드

Discord Webhook URL은 Windows DPAPI로 암호화되어 현재 Windows 사용자만 해독할 수 있는
로컬 설정 파일에 저장됩니다. Discord Client Secret과 실제 운영 환경의 Worker 설정은 이
배포 저장소나 소스 저장소에 포함되지 않습니다.

Discord 간편 연결 및 역할 선택 과정에서 사용하는 임시 세션 정보는 Worker에 최대 10분만
보관되며, 플러그인이 연결 정보를 가져가거나 유효 시간이 지나면 삭제됩니다. X 기능은 API
토큰을 저장하지 않으며 게시 전 사용자가 직접 내용을 확인하고 전송합니다.

플러그인 소스 코드, 빌드 방법, Discord 연결용 Worker 구성은
[StreamPing 소스 저장소](https://github.com/TereBin/StreamPing)에서 확인할 수 있습니다.
