## StreamPing 0.3.1

### Highlights

- Connect Discord by selecting a server channel through OAuth; manual webhook entry remains available.
- Test Discord notifications directly from the OBS settings window.
- Open an X compose window with a customizable message when streaming starts, without an X API key.
- Check CHZZK LIVE status through the public endpoint using native Windows TLS.
- Install or update automatically by running `install.cmd` after closing OBS Studio.
- Keep Discord and X message editors consistent, with advanced LIVE polling settings collapsed by default.

### Requirements

- Windows 10 or later
- OBS Studio 64-bit
